1. Visión del Proyecto

Ecoclasifica es un proyecto tecnológico y educativo orientado a promover la cultura del reciclaje en Colombia mediante el uso de inteligencia artificial y visión por computador.

La propuesta busca desarrollar un sistema capaz de apoyar la clasificación de residuos reciclables, facilitando que ciudadanos, estudiantes, instituciones y comunidades puedan identificar de manera más clara cómo separar los residuos y participar activamente en procesos de reciclaje circular.

El proyecto no se limita únicamente a construir un modelo de inteligencia artificial. Su propósito también es generar conciencia ambiental, fortalecer hábitos sostenibles y demostrar cómo la tecnología puede utilizarse para resolver problemas reales relacionados con el medio ambiente.

5. Herramientas y Entorno de Trabajo

Visual Studio Code

Se utilizó Visual Studio Code como editor principal para crear y organizar la estructura del proyecto.

Python

Python fue seleccionado como lenguaje principal para las futuras etapas de inteligencia artificial, procesamiento de imágenes y visión por computador.

Ollama

Se instaló y configuró Ollama como herramienta de inteligencia artificial local para apoyar el trabajo técnico desde el computador.

Continue

Se integró Continue dentro de Visual Studio Code para trabajar con asistencia de inteligencia artificial durante el desarrollo.

GitHub

Se utilizará GitHub como repositorio técnico oficial del proyecto, permitiendo registrar avances, controlar versiones y mostrar evidencia del proceso de construcción.

Google Drive

Se utilizará Google Drive como espacio de almacenamiento y colaboración para actas, informes, capturas, documentos de entrega y presentaciones.

6. Justificación del Uso de Inteligencia Artificial Local

Se decidió trabajar inicialmente con inteligencia artificial local mediante Ollama por las siguientes razones:

Posibilidad de trabajar sin depender totalmente de internet.

Mayor privacidad y control sobre la información del proyecto.

Reducción de costos frente al uso permanente de servicios de nube.

Aprendizaje técnico real sobre entornos locales de inteligencia artificial.

Apoyo constante para escribir, revisar y comprender código dentro del entorno de desarrollo.

Esta decisión permite que el equipo aprenda no solo a usar herramientas de inteligencia artificial, sino también a comprender mejor cómo se integran dentro de un flujo de trabajo técnico.

9. Descripción de Carpetas

app

Carpeta destinada al prototipo funcional o futura aplicación del sistema.

dataset

Carpeta donde se almacenarán las imágenes utilizadas para entrenar y validar el modelo de visión por computador.

docs

Carpeta destinada a la documentación formal del proyecto, incluyendo actas, informes, arquitectura, roadmap y presentaciones.

modelo

Carpeta donde se guardarán los modelos de inteligencia artificial entrenados.

notebooks

Carpeta para experimentos, pruebas y análisis mediante notebooks de Python o Jupyter.

src

Carpeta principal del código fuente del proyecto.

web

Carpeta destinada a la página web responsive de Ecoclasifica.

LICENSE

Archivo de licencia del proyecto.

README.md

Documento principal de presentación técnica del repositorio en GitHub.
